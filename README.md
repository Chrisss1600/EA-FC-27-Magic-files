# EA-FC-27-Magic-files
"Magic Files" EA FC 27 Versão Standard

# Passo a Passo para instalação

1. Baixe o FC27 Lite no Steam, EAapp ou Epic Games (é recomendável usar uma conta secundária).
2. Inicie o jogo e complete o tutorial.
3. Feche o jogo e todos os clientes do Steam, EAapp ou Epic Games.
4. Acesse a pasta do jogo e exclua os arquivos FC27.exe e dbdata.dll.
5. Baixe e descompacte o arquivo com os "Magic Files".
6. Da pasta "MagicFiles", copie todos os arquivos para a pasta do jogo. Ao copiar, será solicitado para substituir os arquivos, confirme a substituição.
7. Inicie o arquivo origin_helper_tools.html.
8. Clique em "Obter informações da licença".
9. Em seguida, clique no botão "Selecionar arquivo".
10. No explorador de arquivos, na parte superior, insira %ProgramData%\Electronic Arts\EA Services\License e pressione Enter.
11. Selecione o arquivo 16425884_sc.dlf.
12. Copie o "Denuvo token".
13. Acesse a pasta do jogo e abra o arquivo anadius.cfg com o Bloco de Notas.
14. Substitua o texto "PASTE_A_VALID_DENUVO_TOKEN_HERE" pelo texto que você copiou (entre aspas).
15. Feche o Bloco de Notas salvando as alterações.
16. Na pasta do jogo, abra o arquivo token.ini com o Bloco de Notas e substitua "PASTE_A_VALID_DENUVO_TOKEN_HERE" pelo texto que você copiou.
17. Feche o Bloco de Notas salvando as alterações.
18. Inicie o jogo através do arquivo FC27.exe na pasta do jogo.
19. Jogue.
20. É possível desativar as atualizações do Windows usando o programa da pasta "Windows Update Blocker" ou qualquer outro método, para evitar que o jogo seja desinstalado. Além disso, a ativação pode ser perdida durante a atualização dos drivers.
